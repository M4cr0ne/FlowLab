MANUALE RAPIDO

Tutto quello che serve per iniziare

Dalla costruzione del diagramma alle espressioni, fino all'esecuzione.

Costruisci il diagramma

  1. Apri Laboratorio e aggiungi un blocco dalla barra laterale.
  2. Trascina il blocco nella posizione desiderata.
  3. Clicca il pallino colorato in uscita e poi il blocco di destinazione.
  4. Per le decisioni, collega entrambe le uscite SÌ e NO.
  5. Seleziona un blocco per configurarlo nel pannello Proprietà.
Premi Esc per annullare un collegamento. Canc per eliminare il blocco o la freccia selezionati.

Esegui e controlla

  1. Inserisci esattamente un blocco di Inizio.
  2. Premi Esegui per avviare automaticamente il diagramma.
  3. Premi Passo per eseguire un blocco alla volta.
  4. Leggi l'output nella console e controlla le variabili.
  5. Premi Reset per ricominciare senza perdere il diagramma.
I dati sono salvati solo nel browser. Esporta il JSON per portare il lavoro su altri dispositivi.

Sintassi delle espressioni

Il laboratorio interpreta un piccolo linguaggio didattico. Non esegue codice JavaScript arbitrario.

Assegnazionesomma = a + b
Operazioni+   -   *   /   %
Confronti>   <   >=   <=   ==   !=
Operatori logici&&   ||   !
Testo"Ciao " + nome
Condizioneeta >= 18

Un'operazione può contenere più assegnazioni, una per riga. Le variabili possono contenere numeri, testo o valori booleani. I nomi delle variabili iniziano con una lettera o un trattino basso, senza spazi.
